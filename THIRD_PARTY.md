# Attribution et inspirations

Mimo is an independent implementation. It was informed by:

- DigiHuman (GPL-3.0): MediaPipe video landmark extraction and frame-oriented processing.
- Mimic: https://github.com/Abadli-Badro/Mimic — inspect its repository license before redistributing copied code.
- Kalidokit (MIT): https://github.com/yeemachine/kalidokit — hand/pose solving concepts, vector math, and finger angle mapping.

No source file from those repositories is copied verbatim into Mimo in this change. Confirm license compatibility before incorporating external code directly.
